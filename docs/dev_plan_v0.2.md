## 5. 任务拆解

### M1 地址与生命周期

- runtime 地址枚举采用可注入纯函数；过滤 loopback、未启用与非 IPv4，保留多个私网候选。
- `/api/runtime` 返回版本/端口/候选；终端打印推荐地址；页面可复制；本机页面可确认关闭服务，LAN 请求无权关闭。移动端不在范围，因此不提供二维码。
- `sweepExpiredRooms` 只过期未配对房间；已配对房间以活动/断连清理。
- 验证：确定性单测、服务器集成、浏览器首页。

### M2 连接与存储合同

- 为 RTC 协商建立可取消的 8/20 秒时钟与阶段事件；失败保留货单。
- 生成脱敏诊断；所有失败有错误码和用户出口。
- 在接收清单阶段预检单文件/批次 256 MiB。
- 验证：虚拟时钟、错误注入、UI E2E。

### M3～M4 中转

- spike 选择可离线打包、LAN HTTP 可运行的审计密码实现；已知向量、随机数、密钥协商、篡改拒绝、销毁测试为硬门禁。
- 中转 token 绑定房间/角色/单次使用；服务端仅处理包络和有界密文队列。
- 协商序列：发送方申请→接收方批准→双方拿凭据→密钥握手→清单批准→chunk。
- 验证：零字节门禁、明文扫描、乱序/重放/篡改/慢端/取消/掉线/超限。

### M5 指标

- 接收端连续写入 ACK；发送端确认进度单调校验。
- 250 ms UI、2 秒当前速度窗口、全程平均、稳定后 ETA。
- 建立相同设备/网络/文件的前后基线后再改 chunk/watermark。

### M6 跨系统

- 构建 win-x64、darwin-arm64、darwin-x64、linux-x64。
- 每产物启动并校验 health/runtime/静态资源；文档覆盖未签名启动。
- 真机矩阵按设备、浏览器、方向、大小、路径、吞吐、哈希记录；缺项标待补证。
