## 最近验证

- 验证时间：2026-09-04
- 验证方式：`bun test`；`python -u tests/ui_prototype_test.py`；从最新 `dist/dukou.exe` 启动服务后执行 `python -u tests/e2e_transfer_test.py --base-url http://127.0.0.1:4123`。
- 结果：Bun 全量 91 个测试通过、0 失败、302 个断言；两项真实 Chromium 验收退出码均为 0；bundle 与 Windows 单文件程序构建成功。
- 证据：两个隔离浏览器完成建房、输码、发送方批准、已知非中继 ICE 路线确认、清单批准、65,537 字节跨 5 个分块传输与下载；下载逐字节一致。另覆盖未保存返回确认、关页 OPFS 清理、桌面/390×844 视口与控制台错误。
- 证据状态：新测；适用于当前源码与 2026-09-04 生成的 Windows `dist/dukou.exe`。
- 失效条件：`src/`、构建脚本或浏览器 E2E 合同发生相关变化。
